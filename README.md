</p>

---

<h2>✨ About the Project</h2>

<p>
<b>FreeCanvas</b> is a lightweight and interactive drawing canvas that allows users to draw freely with natural hand strokes.
It is designed to feel like real paper — simple, smooth, and unlimited.
</p>

<p>
This project focuses on creativity, minimal design, and real-time free-hand drawing experience.
</p>
